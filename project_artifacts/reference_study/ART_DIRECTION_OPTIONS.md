# Art-direction options for NAKHLA (original, Basrah-specific)

These are three original directions drawn from patterns in the reference study, not copies of Form Architects' buildings. They work within the real NAKHLA brief:
- a 12-storey tower on a 24 × 32 m plot;
- 18 apartments (9 × Type A and 9 × Type B on F01–F09);
- an F10 wellness club and an F11 restaurant, café and terrace.

None is owner-approved.

## Option 1 — "Shaded oasis" (recommended for now)

| | |
|---|---|
| **Silhouette** | Today's tower is kept. The façade frame continues above the roof as an open crown that screens the plant (≈2.6 m). The frame reads as a lantern at night |
| **Materials** | Ivory stone frame, bronze-coated fins (today's), warm teak soffits, deep-set dark glazing |
| **Day / golden / night** | Day: the crisp frame shadows of today. Golden: warm stone against palm silhouettes. Night: the crown lit from inside, warm windows, uplit palms on the plot |
| **Urban to the horizon** | Tree-lined district avenues, small planted squares, parked cars within 250 m; plain hazy massing beyond (as now) |
| **People and traffic** | Traffic as now; people when the owner approves CC0 assets |
| **3D budget** | +≈60–90 k triangles (trees and cars, low-poly); about +10 draw calls (new buckets) |
| **Fit with the brief** | Full. No plan change |
| **Change from now** | Context density (trees and cars) and night light points; crown as an option |

## Option 2 — "Mashrabiya lantern"

| | |
|---|---|
| **Silhouette** | The F10–F11 amenity floors get a perforated bronze screen wrap (an original pattern, not a copy), so the top two floors glow at night |
| **Materials** | Bronze perforated panels; the rest as today |
| **Budget** | The screen texture is a single alpha-masked material: low in live, medium in Cycles |
| **Fit** | Good, but it changes the amenity façade the owner has seen. **Owner review needed** |

## Option 3 — "Garden podium"

| | |
|---|---|
| **Silhouette** | The ground floor and forecourt become a raised garden podium with planters stepping up to the lobby, and pergolas over the side yards |
| **Materials** | Stone planters, teak pergolas, gravel and paving |
| **Budget** | Medium |
| **Fit** | Needs a site-plan decision (the plot is a 24 × 32 m hypothesis), so it must wait for the owner |

## Choice

**Option 1**, because:
- it improves exactly the weakest scores (context and night) without changing the architecture the owner has reviewed;
- it fits the frame budget;
- its crown element stayed optional until the owner looked at it. **Update 2026-11-14:** the owner reviewed a preview and adopted the crown (D18).
