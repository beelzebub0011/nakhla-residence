# Research leads / verified public reference anchors

- MDN autoplay policy and HTMLMediaElement / WebAudio interaction rules: https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay
- W3C WCAG: page language and language-of-parts, accessible semantics: https://www.w3.org/WAI/WCAG21/Understanding/language-of-page
- Unicode: Kurdish Arabic script and Sorani characters: https://www.unicode.org/versions/Unicode17.0.0/
- Unicode CLDR: locale patterns and language-specific conventions: https://cldr.unicode.org/
- W3C internationalization: https://www.w3.org/International/

Research up-to-date runtime/browser compatibility and maintain evidence in project_artifacts; don't blindly accept a library's defaults for ckb-IQ, Arabic pluralization, WebAudio or PDF fonts. References are guidance, not proof that built code passed.
