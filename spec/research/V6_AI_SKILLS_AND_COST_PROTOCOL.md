# V6 — AI RESEARCH, RELEVANT SKILLS AND COST APPROVAL PROTOCOL
Research available project-scoped tools rather than blindly installing popular AI agents. Claude may inspect environment, find and vet reliable open-source libraries for localized intent detection / typo handling / transliteration, React accessibility, schema validation (Zod/JSON Schema), geometry measurement, state/store selectors, lightweight text search, safe PDF rendering, i18n and Playwright/browser QA. Verify source repository, license for commercial website, maintainer activity, security notices, transitive deps, package versions, file integrity and export size. Pin versions and install only after source review. Avoid overlapping libraries and huge SDKs. Use available already-installed skills before adding more; log installed tools and rationale in templates/SKILL_AUDIT_TEMPLATE.md.

Zero incremental budget is default: do NOT purchase inference APIs, cloud speech-to-text, GPU instances, LLM credits, translation subscriptions or SaaS without owner permission. Do not auto-enable external cloud calls to a stranger's LLM endpoint. The factual local assistant is the P0 baseline, preferably pure TypeScript and existing app data. Suggest an LLM option as a separate documented P2 tier if benefits vs costs/security justify it. If a model could be run server-side for a future commercial site, quantify actual infrastructure, latency, translations, data policy and abuse budget before recommending. Public access requires separate user authorization and privacy/legal review. No false claim of "AI reads any question" when local parser coverage is bounded; honest unknown answers are part of quality.
