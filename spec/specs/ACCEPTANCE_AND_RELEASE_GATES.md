# Phase gates and definition of done

Gate 0 — Evidence-based reconnaissance: environment inventory, screenshots/video inspected, original assets inventoried, licenses identified, skill security review performed, official documentation referenced, no duplicate installs, budget clear.
Gate 1 — Decision-grade research: at least 3 defensible architectural/site options and technical architecture alternatives considered, sources dated, assumptions labeled, major red flags in risk log, chosen solution with ADR and rationale. Do not spend endless time researching: stop when incremental information ceases to change the decision.
Gate 2 — Architecture geometry: tower exactly G+01–11, geometry stack consistent, two units for floors 01–09 only, amenity zones correct, conceptual square meters identified, windows align interior, unique clickable IDs, basic cutaway validated.
Gate 3 — Visual quality: photoreal-ish original/legit exterior hero and at least one stunning living room, believable room dimensions, realistic light and PBR, usable mobile poster; 3D rendering used where feasible, no flat cube pseudo-production assets. Visual comparison screenshots reviewed and improved.
Gate 4 — Functional core: floor hover and keyboard list, selection, camera focus and reversal, apartments and amenities, dollhouse->room transition, 6 classes of material inspector, live swappable materials, persistence and reset, day/night and xray or honest fallback, gallery, demo request/summary.
Gate 5 — Delight and consistency: guided tour interruptible, transitions don't fight controls, honest gallery/package synchronization, high polish, dark/warm tasteful typography, responsive controls.
Gate 6 — Reliability/accessibility: tsc/lint/unit/e2e pass, WCAG-oriented audit, keyboard and mobile touch, reduced motion, 2D fallback, GPU context loss, no dead CTAs, no broken text. Arabic and English fully tested.
Gate 7 — Shipping: local site launches in fresh checkout, deterministic startup instructions, licenses/assets, original .blend sources or source-of-truth scripts, performance observations, screenshots/video capture proof, honest completion report with known limitations.

Milestone strategy (autonomous): vertical slice in this order: beautiful exterior + one clickable residential floor -> real apartment cutaway -> one hero living room with one real material swap -> full six-category configurator -> amenities -> export/summary -> polish. Resist building all pages as decorative shells before first working 3D slice. If engineering constraints require different order, document rationale.

Exit gate requirements: All P0 blocking issues resolved or explicitly surfaced with independent usable fallback; visual signoff comparative captures; architecture consistency automated assertions; no copyrighted/unsafe assets; no false claims; no required paid service; no critical known functional defect.
