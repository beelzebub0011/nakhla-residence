# Additional standout ideas — prioritized without derailing core MVP

P1 only after base functions work:
1. Seamless automatic 3D guided "Sales Presentation Mode" showcasing tower -> floor -> Type A -> living material swap -> wellness -> dining -> finish board, with pause/skip and actual timed camera shots.
2. Building X-Ray with truthful per-level volumes, core services and transparencies; dedicated touch-safe UI alternative. Do not invent unseen furnished rooms.
3. A/B split or swipe comparison between warm/pearl finish presets with identical camera and lighting; non-pointer toggle.
4. Time-of-day preview: sun movement/sky lighting (artistic approximation unless real geolocated site/orientation measured), room lights dimmer and night facade.
5. Furnished / unfurnished toggle, only if original model supports layer groups; extremely useful to show construction versus styled ambiance.
6. Two-unit comparison: see Type A and B plan, room count, concept area and render; clearly no real sales inventory.
7. Material Passport/Finish Board share as polished PDF with a full named sample list and illustrative nature of finishes.
8. Project cutaway "How it Works" mode: visible core vs apartment vs facilities, press labels.
9. Accessibility-friendly 2D plan with tappable room polygons; no essential content limited to hovering in 3D.
10. Performance and visuals toggle "Cinematic / Balanced / Data Saver" with transparent browser capability hint.
11. Multiple camera presets and orbit/auto-orbit stopped on pointer input; control resets.
12. Architectural sustainability storytelling cards about shading/reduced west glass and materials, explicitly conceptual not energy certification.

P2 candidate ideas for a paid version (never required for portfolio demo):
13. AR glTF USDZ model preview on supported devices only after compatible export and proper permissions.
14. Sales-room kiosk mode with local autoplay, idle reset and QR code to continue apartment on phone.
15. Multi-project property CMS, mapping BIM/IFC data to verified geometry, rev-control of floorplans and sales records.
16. Real availability statuses synced to property ERP and audited dates; price quotation versioning/currency and Arabic PDF.
17. Verified supplier product lookup, material procurement availability, SKU/product and pricing region by region.
18. Solar exposure heatmap for specific geolocated/oriented real site only after physically appropriate simulation.
19. Outdoor view projections using real surveyed location/terrain, requiring licensing and disclosure; avoid fiction made to look like verified panorama.
20. Interactive furniture package swaps with accurate scale, not false claim inventory included.
21. Unit locator in larger multi-tower complex with GPS/map and accurately cited live address.
22. Verified green/thermal performance certificates and buyer transparency dashboard after actual engineering verification.
23. Live private tours with sales representative, reversible camera handoff and privacy protections.
24. Client wishlists, favorites, appointment CRM, secure developer admin and per-organization settings.
25. Optional export of user's chosen material palette to external design software/interoperable format.
26. Multi-language support beyond AR/EN, selective localization, documented stakeholder accessibility testing.
27. Composed take-home video tour from actual scene cameras and original music; use Lemo-Opuscar if vetted/relevant, not as website dependency.
28. Tiny original 3D avatar/motion logo optional only if it supports brand identity and doesn't increase load.
29. Transparent cost-of-upgrade table based solely on developer-entered confirmed prices.
30. Developer version and content audit trail when units or finish catalog changes.

Selection rule: any enhancement must first satisfy direct business value, no extra costs, no degradation of core frame rates, mobile fallback, low cognitive load, appropriate licensing. Keep a ranked optional backlog and do not use optional features as a pretext to ship an unfinished core.
