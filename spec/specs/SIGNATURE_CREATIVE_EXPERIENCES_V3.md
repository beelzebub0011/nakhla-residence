# V3 — EXTRAORDINARY IDEAS WITH MEASURABLE VALUE, NOT A BLOATED WEBSITE

Claude MUST shortlist innovations using: buyer value, architectural truthfulness, wow factor, implementation complexity, device performance, rights/license, privacy, maintainability, and portfolio demonstration value. Implement Tier A after core app and basic performance passes; Tier B only when affordable/low-risk. If optional effects degrade user experience, auto downgrade or feature-gate instead of harming the baseline.

## Signature 1: One Continuous Camera Journey
A composed, plausible transition from boulevard / tower facade -> highlighted floor -> split slab -> dollhouse -> clicked living room -> material surface, preserving spatial orientation. On low-tier use seamless frame-matched still cuts, never blank screens. Include exact camera bookmarks and no wall clipping.

## Signature 2: The Living Building / يوم داخل نخلة
One optional condensed day-in-the-life interactive montage: sunrise at balcony, midday facade shading, sunset indoor materials, evening café, night pool illumination. Change time while following the same camera framing where possible. User controls playback; never force full animation.

## Signature 3: Sun & Comfort Lens
Show simulated sun path and conceptual shading envelope to help users see which balcony gets direct light; overlay orientation disclaimer until actual north and geography verified. Show clear/summer vs golden-hour/winter compare at a chosen viewpoint, without claiming measured comfort or energy rating.

## Signature 4: Live Material Atelier
Color and roughness swatches cause real PBR material changes to registered surfaces with physically plausible lighting; package A/B split reveal and finish-board generation. Full 'my selections' card preserves surface IDs. A realistic gallery photo that doesn't match is honestly 'illustrative'; generate true current-scene screenshot as optional alternative.

## Signature 5: X-Ray Architecture and Accessible Transparency
Click 'See Inside' to reveal 3D floor stacking/cores, trace selected unit to facade and balcony. Reveal real modeled geometry only, never fake building services without verified drawings. Use scalable proxy meshes on mobile. Show section plane and ghosted exterior when possible.

## Signature 6: Floor-to-View Reveal
At each floor, camera moves to balcony viewpoint; show Basra-inspired illustrative skyline, approximate orientation and concept disclaimer. This emotionalizes floor selection without falsely advertising a real view of a real neighborhood.

## Signature 7: Personal Film / Shareable Design Moment
Save a personalized, screenshot-based card of current floor+room+materials+sky preset with embedded concept notice and creator credit. Compact share link restores safe, validated state without uploading buyer information. Generate social preview image with readable Arabic RTL/English titles. Lite alternative exports a branded 2D summary; no cloud renders required.

## Signature 8: Salesroom Theater Mode
'Present to Client' enlarges 3D, hides dev-oriented controls, increases font/click targets, and guides a scripted 3–5 minute live sales narrative. Salesperson can interrupt and answer a client's question then return; use authentic diagrams and known fields only. Option to prefetch limited key scenes on Wi-Fi, without huge first-download cost.

## Signature 9: Quiet Luxury Mode
One-tap minimal HUD, zero sound, zero unnecessary motion, stable orbit/guided navigation, reduced weather particles; beautiful for older users, motion-sensitive visitors and investors using a big screen. Not a lesser visual quality, it is deliberate sophisticated restraint.

## Signature 10: Contextual Intelligence (no expensive AI API)
Contextual prompts drawn from semantic metadata: 'You are on Floor 04. See balcony', 'Change floor finish', 'Compare Standard and Premium'; local app rule engine, no external model API, no personal profiling. Tiny helpful prompts that disappear after use, not a chatbot that blocks the experience.

## Signature 11: Architectural Detail Story
Opt-in callouts describe why the facade uses shading fins, why chosen material has a particular finish, and differences between conceptual specification and actual manufacture. Link product information only if verified. A meaningful educational layer differentiates sales platform from a flashy render.

## Signature 12: Spatial Audio (optional, never default)
Very soft original ambience or licensed street/birds/water sounds with per-scene controls. No autoplay, no surprise sound on navigation, mute as global state, reduced-data switch. Every sound file documented in asset-license ledger.

## Core-value feature selection
Must ship MVP: modes, functioning project explorer, material live edit, environment options, accessible navigation, performant mobile, designer-grade UI, creator credit and honest demo CTA.
Worth adding before portfolio showcase if QA passes: continuous transitions, curated intro, one day-in-life sequence, one cutaway, view reveal, finish export, salesroom mode.
Future/optional: truly accurate solar data, dynamic 3D weather effects on all devices, personalized real-time full-quality render server, VR/WebXR, AI assistant, live inventory CRM, real quotes.

## Acceptance rule
NO feature may claim all possible designs, exact weather, view, price, finish availability, health safety, or building standards as facts. Deliver visually extraordinary *but trustworthy* demo. Implement spectacular features only when they survive the responsiveness and FPS/device gates.
