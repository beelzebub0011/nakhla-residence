# V5 — SALESROOM PRESENTATION, STORYTELLING AND A REUSABLE BUSINESS PRODUCT

## Day-in-Your-Future-Home (P1)
A deliberate user-activated 'يوم في نخلة' interactive short story inside Tour, with 5 skippable chapters: (1) sunrise balcony, (2) living and material detail, (3) afternoon wellness/gym/pool, (4) sunset dining/cafe, (5) night exterior. Cinematic camera, optional captions in all 4 languages, NO sound without explicit opt-in, reduced-motion chapter stills and Lite HTML carousel. Every chapter is an authentic prepared scene/camera anchor; cancellation at any point restores last user room/finishes/time unless user chooses 'Apply Scene Settings'. Keep one renderer active; preload one next chapter at a time, not all assets in initial transfer. Target a concise ~60–100s optional experience, timing flexible. Do not imply pool/spa/shisha legally approved or real construction exists.

## Presentation Room (P1)
An opt-in salesperson-friendly presentation action under utility/More (not a fifth section): large 3D, big readable labels, minimal panel, sequence 3–5 minutes focusing on buyer value. Prev/Next/Jump/Exit, keyboard and tablet control, capture/resume current viewer state, audience-friendly captions 4 languages; no secrets in screen share. Free roam from specific chapter and return to sequence. Option to share QR/link so viewer opens same safe scene on own phone. Never auto-deploy, record, track viewers or claim connected CRM. Preload lightweight key scenes on Wi-Fi with budget and consent, not giant assets.

Single configuration schema for branding, project slug, multilingual strings, materials, floor mapping, facilities, camera anchors, optional featured tours, opt-in features, ownership footer and developer contacts. A new project must be loadable without rewriting core renderer logic and without inheriting Nakhla ownership claims. Validate each imported project's asset licensing, structural dimensions, fallback geometry, labels, UI localization keys and legal claims before publish. MVP: static tenant config + clean documentation; full version: permissioned CMS/editor/importer. Never host real client data or images in public repository without authorization. Do not transfer ownership of third-party assets by copying copyright footer.
