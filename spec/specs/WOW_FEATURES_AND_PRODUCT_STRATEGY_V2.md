# WORLD-CLASS WOW FEATURES — MEANINGFUL, OPTIONAL, BUDGETED

## Strategic goal
The result should make a property developer say "I want my project presented this way" while still being easy for an ordinary client who opened a link in WhatsApp. WOW is not hundreds of fireworks or random UI motion; it is useful interactive spatial storytelling, personalized finishes and emotional but tasteful presentation. Every additional feature needs a demonstrable sales/clarity benefit, measurable performance cost, accessibility alternative, original/licensed assets and a graceful off switch. Never inflate scope so the hero experience remains half-built.

## TIER 0: always complete before experimental extras
1. Cinematic 3-second-to-skip intro using static poster immediately and GPU scene only when ready; gorgeous but optional.
2. Real 3D tower and 12-level browser with selector list mirrored in DOM.
3. Select apartment A/B, see accurate cutaway, enter hero Living/Kitchen/Master/Bath/Balcony, walk/guided room hop.
4. Examine actual material details + changing PBR surface live + finish packages + undo/reset.
5. Visit Gym/Pool Level 10 and Café/Restaurant Level 11 with actual reliable 3D navigation.
6. Set time, weather and season; state preserved; suitable mobile Lite mode.
7. Beautiful original, coherent render gallery + information + print/export and truthful demo inquiry.
8. Consistent good performance under mobile constraints, bilingual responsive/accessibility and stable link.

## TIER 1: strong differentiation, add only after baseline passes
A. **Virtual Architect / Guided Explorer**: short optional story chapters, move through building, floor plan, room, materials, amenities, return to summary. Each chapter has precise skip/stop and translated copy. Can create a personalized demo route from currently selected unit, no generative API/hidden costs.
B. **Solar & Shade Discovery**: `Where does the sun reach my apartment?` uses notional site north and time/season and explicitly simulated shadows; let buyer observe balcony shade and sunlit room, with a notice that it is conceptual rather than a certified energy study. Adds value specifically for hot-climate Basra.
C. **Instant Before / After / Package Split**: compare Standard vs Premium or original vs personalized finishes by smart material change not duplicate high-poly scene; usable slider accessible on keyboard; when scene cost high, capture A screenshot then B and compare 2 stills with honest labels.
D. **Building X-Ray / Peel-Away**: facade gradually becomes translucent/floors separate to show shared corridors and apartment location. Never render all furnished 18 homes simultaneously; simplify underlying interiors. Optional `Infrastructure Reveal` later only if drawings exist.
E. **True Perspective View from This Floor**: select floor, camera aligns to approximate balcony viewpoint and shows a fictional Basra-inspired skyline aligned to notional orientations. DO NOT fake a view of an actual neighborhood/river as factual. Add `Compass/North` and illustrative sunlight.
F. **My Apartment Collection**: visitor favorites options, side-by-side compare 2 floor types, bookmark room + camera + environment, share compact view link and print-to-PDF selection cards. Privacy-friendly local state by default, no signup wall.
G. **Material Passport QR / Smart Spec Board**: downloadable no-brand-infringement finish board with catalog IDs, actual metadata source and fictional concept stamp, side-by-side color chips and suggested performance properties only if verified; no invented manufacturer certifications.
H. **One-Click Cinematic Screenshot**: capture user's current 3D view and an optional captioned marketing image. On low tier capture at current render quality, not fake 8K; no uploading camera/frame to server unless opted in.
I. **Salesperson Presentation Mode**: one button hides dev UI, shows simplified floor selector and prepared 5-minute walkthrough; offline or prefetch mode documented, no automatic pub. Allows buyer to step in at any time.
J. **Design Pulse**: tap a room to see count of selected finish alternatives and category status; visually subtle, no gamification distracting from purchase.

## TIER 2: future paid product possibilities (do not block MVP)
- Editable project CMS where clients import plans, BLEND/GLB, finish catalogs and gallery; validation creates floor/unit/surface mapping.
- Studio-level renders generated on server with a queue (costed and opt-in) matching custom finishes exactly, not fake real-time instant GPU ray tracing on mobile.
- CRM inquiry, scheduled tours, property availability sync, lead permissions, authorized company admin.
- Accurate BIM/IFC import, MEP/service cutaways, clash review and spec traceability by licensed architect/engineer.
- Multi-unit compare with mortgage/financing, price calculation and standardized sale documents only with real developer data and approvals.
- VR/WebXR when hardware supports it and reviewed security/accessibility; no forced headset.
- Home furnishing configurator with SKU/licensing and delivery integration only after clear agreement.
- Optional real weather API, precise solar study, construction time-lapse from legitimate media, measured sound insulation and energy score — NEVER fabricate metrics.
- Optional AI sales assistant restricted to documented project facts and transparent limitations, only if business value outweighs runtime/API/privacy costs.

## Distinctive hero scenarios the developer can demo
1. User opens link on a midrange phone; within short wait sees responsive hero and floor picker even as 3D downloads. Taps Floor 04 -> A -> Living; changes porcelain to oak. No spinner trap, no jump. 2 minutes.
2. On an iPad, shows 10 Wellness; moves inside Gym, navigates to pool; changes environment to Sunset + Winter Light Rain; reflection/sky changes appropriately, pool never receives exterior rain. 1 minute.
3. On a laptop, use Daylight Detective: point compass to afternoon summer sun, examine balcony shade, compare against golden-hour spring, identify sunlit side. 1 minute.
4. On desktop, one-click guided cinematic full tour; pause to freely explore master bedroom, inspect walnut sample, save report, generate demo inquiry (locally only). 2 minutes.
5. On a low-power phone or WebGL unsupported: click `Lite`, select floor, see plan and representative stills, inspect material spec and receive honest PDF — full commercial narrative still accessible.

## UI style / restraint
Modern Iraqi Luxury: warm-ivory stone, sophisticated bronze accents, dark charcoal typography or optional dark theme, Arabic-first identity, generous breathing room, refined motion, high-quality iconography, tactile photos, clear interactions. Luxury does NOT mean unreadable tiny text or overloaded glass-morphism. Add no looping video background, no autoplay audio, no massive particle weather effect, no invasive popups, no deceptive synthetic neighborhood claims. Design and proof with actual screenshot comparisons.

## Hard priority override
If any TIER 1 feature causes mobile regression, downgrade it or defer; if any TIER 2 proposal requires credits, licenses, external accounts or user data, document as future optional — DO NOT install/run/pay by default. Do not claim 100% completion if future ideas were intentionally scoped out; label what is ready vs roadmap.
